## Root cause and fixes (`8280c97`)
1. vLLM 0.10.1.1 declares only `transformers>=4.55.0`; uv installed 5.22.2, which removed an attribute vLLM uses. The environment now installs the libraries of vLLM's release date (transformers 4.55.2, tokenizers 0.21.4, huggingface-hub 0.34.4; newest before its PyPI upload on 2025-08-20), or `requirements.lock` once it exists, and installs our requirements with that freeze as constraints (as the Dockerfile does). The Docker image is not affected: the base image ships its own transformers and the project requirements cannot change it.
2. The notebooks stop at once on a GPU with compute capability < 8.0 or < 22 GB, and GPU_CHECK checks that vLLM can load the tokenizer before any run.
3. The restart cell kills only the server's process group.
