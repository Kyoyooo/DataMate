# Runbook — full training run and public test on Colab

`notebooks/colab_bootstrap.ipynb` (generated by `tools/make_colab_notebook.py`) runs, in order:
1. a **smoke test** on 30 training questions (always; stop if it fails);
2. the **full training run** (`RUN_FULL_TRAINING = True`, TASKS L-06): every training question through the evaluation
   harness, then PA by type and reason code, the error analysis (L-14) and a runtime projection (M4-08);
3. the **public test** (`RUN_PUBLIC_TEST = True`): one merged `submission.jsonl` for the Round 1 leaderboard.

Both long runs save every finished part to Drive. After a disconnect, a failure or a session limit, *Run all* again with the
same run names (`TRAIN_RUN`, `PUBLIC_RUN`): finished parts are skipped. A run folder only continues with the same commit,
model, config, GPU memory setting and fold/chunk size; change anything and the notebook asks for a new run name, so one
result never mixes versions.

## What this is and is not
- Round 1 is for development: the public leaderboard is a reference only (COMPETITION_BRIEF §5.1). The final score comes
  from the organizers' re-run of the frozen Docker image on 2 × RTX 5090 (§5.2 rule 8). These Colab runs do **not** replace
  the image, the private-test run ([private-test-run.md](private-test-run.md)) or the 2 × RTX 5090 timing and
  reproducibility checks.
- The training PA is the measure for decisions (harness, whole-business folds). Never tune prompts, rules or few-shot
  examples on public-test questions or on per-question leaderboard feedback (§5.2 rule 6).
- Never commit training or public-test data, submissions, logs or error-analysis samples: the repository is public. They stay
  on Drive. Aggregate numbers (PA, PA by type, timing) may go into `docs/evidence/`.

## Before the session
- Push the branch you want to run (Colab clones it from GitHub) and set `BRANCH`. Until `lead/phase-2-gpu-results` is merged,
  use that branch: it has the library pins without which the model server does not start.
- `MyDrive/DataMate/train.zip` (the training split). For the public test also `MyDrive/DataMate/public_test.zip`
  (set `PUBLIC_ZIP` if the name differs) or an unzipped copy in `MyDrive/DataMate/data/public_test/`; it must contain one
  folder with `questions.jsonl` and `rulebook.md`, and no `answers.jsonl`.
- GPU: **G4** if you can select it (Blackwell, like the RTX 5090). Otherwise an **A100**: correct results, but timing is
  indicative only and the Blackwell kernels are not exercised. T4 and TPUs cannot serve the model (the notebook stops).
  Keep one GPU type for runs you compare.

## Run
1. Open the notebook in Colab, set the first cell (`BRANCH`, `MODEL_REPO`, `RUN_FULL_TRAINING`, `RUN_PUBLIC_TEST`, run names)
   and choose *Runtime → Run all*.
2. Full training run: folds of whole businesses (`FOLDS = 5`: 6 businesses, about 600 questions each). Each fold starts and
   stops its own model server and is copied to `MyDrive/DataMate/runs/<TRAIN_RUN>/foldK/` with a `DONE` file. At the end the
   harness evaluates all folds together and the notebook saves:
   `run_record.json` (PA, by type, by reason code, coverage, unanswerable precision/recall, p50/p95 time per question),
   `error_analysis.md`, `projection.json`, `meta.json` (commit, branch, model, GPU, Python environment, minutes per fold).
3. Public test: chunks of `BUSINESSES_PER_CHUNK` whole businesses, each checked with `tools/precheck.py` and copied to
   `MyDrive/DataMate/runs/<PUBLIC_RUN>/chunk-XX/` with a `DONE` file; then `runs/<PUBLIC_RUN>/submission.jsonl` (every id
   once, in the order of `questions.jsonl`). Upload that file to the Round 1 leaderboard.

## Reading the results
- **PA and error classes:** `run_record.json` → `report`; `error_analysis.md` lists every class above 1 % with its owner
  (L-14). The lead turns those into tasks (M1-14, M2-14, M3-09).
- **Runtime projection (M4-08):** `projection.json` gives hours for 500 and 1,000 questions from the measured total time,
  with one server and one model load per fold. Two RTX 5090 servers are expected to be roughly twice as fast; the target is
  ≤ 50 % of the 6-hour limit. Final numbers come only from a run on 2 × RTX 5090.
- **Determinism (L-15):** run the training run twice with two run names, copy both folders locally and run
  `python -m datamate.eval.harness compare <run A> <run B>` (|ΔPA| ≤ 0.005 is the L-15 target).
- Only `submission.jsonl` of the public test is merged; each chunk and fold keeps its own genuine `logs/` and `run.json`.
  Settings are `config/colab.json` (one replica, about 32 GB of GPU memory) plus the model path and vLLM command set by the
  notebook; `model.path` in `config/run_config.json` stays `UNSELECTED` until DEC-3 (L-13).
